# 7th Grade Math

Static study site: one folder per lesson under `lessons/`. Each lesson has a short narrated video,
big-idea overview, interactive explorers, a concept check, and randomly generated practice problems.

- `assets/css/style.css`: shared styles
- `assets/js/graph.js`: SVG grid plotting + number parsing helpers
- `assets/video/`: lesson videos (made with Manim; source lives outside this repo)
- `lessons/dilations-slope/`: Lesson 1 (scale factor, center of dilation, slope)

To add a lesson: copy a lesson folder, edit it, and add a card to `index.html`.
